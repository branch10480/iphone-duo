# 全画面機能監査 — 計画と進捗（2026-09-22）

> ユーザー依頼: 「各画面の機能がちゃんと動いているか（タップできるはずなのにタップしていない、画面分割されるのにされていないなど）を調べて全て問題ないように修正する」。
> 本ファイルは計画＋進捗の正。観測値の蓄積先は [引き継ぎ記録](handoff-next-session.md)（§20〜 へ追記）。

## 方法

- 検証環境: iPhone Duo シミュレータ（iOS 27.1、`6B8C075B`）、fresh boot 出発（pose=closed、orientation=portrait）。
- pose 切替: DeviceHub の pose ボタンを `probe2 axpress <pid> "<needle>" one`（`.tmpx/axtest/`）。
- 画面確認: `xcb_screenshot`（画像で判断）＋ `xcb_snapshot_ui`（タップ参照）。
- 各タブで「操作できるものは操作し、状態変化を値・見た目両方で確認」。問題が出たらその場で修正 → rebuild → 再確認。
- 「動かない」の判定は、操作が効かなかった＋表示が変わらなかったの両立で。sim 制約（openWindow 無視など）とアプリ bug を区別する。
